# 📄 Fetch Users Data from API (JavaScript)

## 📌 Project Overview

This project demonstrates how to fetch user data from a public API using JavaScript. It covers two common approaches for handling asynchronous operations:

* Promise-based (`.then()` / `.catch()`)
* Modern `async/await`

The fetched data (an array of user objects) is displayed in the browser console.

## 🎯 Objective

* Make an HTTP request to an external API
* Process the response correctly
* Log the retrieved data to the console
* Understand and compare both async handling methods

## 🔗 API Endpoint

https://jsonplaceholder.typicode.com/users

## ⚙️ Features

* Uses `fetch()` to call the API
* Converts response to JSON format
* Implements error handling
* Demonstrates clean and readable code
* Includes comments for better understanding

## 🛠️ Implementation Details

### 1. Promise-Based Approach

* Uses `.then()` to handle successful response
* Uses `.catch()` to handle errors

### 2. Async/Await Approach

* Uses `async` function for cleaner syntax
* Uses `await` to pause execution until response is received
* Uses `try...catch` for error handling

## 📁 Project Structure

* Single JavaScript file containing both implementations

## ▶️ How to Run

1. Copy the code into a `.js` file
2. Open in browser console or run using Node.js
3. Check console output
